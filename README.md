## Information

ONOFFON은 좋아요 한 번으로 나만의 영화 취향을 저장하고, <br />
최신 인기 영화와 다양한 작품들을 한눈에 탐색할 수 있는 스마트한 영화 플랫폼입니다. <br />
지금, 당신만의 영화 컬렉션을 만들어보세요.

## <a name="features">Features</a>

### 음원 재생

- 키워드를 입력하여 원하는 영화를 빠르게 찾을 수 있습니다.
- 영화 제목, 개요, 평점, 개봉일 등 상세 정보를 확인할 수 있습니다.

### 좋아요 기능

- 마음에 드는 영화를 하트를 눌러 저장할 수 있습니다.
- 좋아요한 영화는 별도 리스트로 관리됩니다.

### 최신 영화 확인

- 인기 영화 및 최신 개봉작을 실시간으로 확인할 수 있습니다.
- 홈 화면에서 다양한 영화 카테고리를 탐색할 수 있습니다.

### 반응형 UI

- 다양한 디바이스(모바일, 태블릿, 데스크탑)에 최적화된 레이아웃을 제공합니다.
- 화면 크기에 따라 UI 요소가 자동으로 조정됩니다.
